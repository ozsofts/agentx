# Project overview

Use this skill when the user asks to understand an unfamiliar repository.

1. Read the repository instructions and package manifests first.
2. Identify runtime entry points, major modules, persistence boundaries, and external services.
3. Verify commands from scripts or documentation before presenting them.
4. Report the result as a compact map with direct file references.

Do not modify files unless the user also asks for implementation.
